# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of age, body size, visible or invisible disability, ethnicity, sex
characteristics, gender identity and expression, level of experience, education,
socio-economic status, nationality, personal appearance, race, religion, or sexual identity
and orientation.

## Expected behaviour

- Be respectful and constructive.
- Assume good faith; critique ideas, not people.
- Give and accept feedback gracefully.
- Respect privacy and do not publish others' personal information.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, publishing private information
without permission, and sustained disruption of discussions.

## Scope and enforcement

This code applies in all project spaces: issues, pull requests, discussions, reviews and
any other channel where someone represents the project.

Report concerns privately to the maintainers through GitHub's **Report abuse** flow or a
private security advisory. Maintainers will review and respond in good faith, and may
remove content or restrict participation.
